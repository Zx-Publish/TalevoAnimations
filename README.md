# Talevo Animations — Updated Website

A responsive, colorful 3D-inspired entertainment website for Talevo Animations.

## Files
- `index.html` — full website and six-second non-skippable opening intro
- `style.css` — responsive UI, 3D-inspired visuals and intro animation
- `script.js` — intro timing, mobile navigation, filters and reveal effects
- `assets/brand-mark.svg` — vector channel logo mark

## Run
Extract the ZIP and open `index.html` in Chrome. No build tools, backend, API key or package installation required.

## Publish on GitHub Pages
Upload the contents of this folder to the repository's `main` branch, keeping `index.html` at the repository root. In Settings → Pages, select Deploy from a branch, `main`, and `/ (root)`.

## Important analytics note
The four featured countries are USA, Bangladesh, Mexico and Peru, displayed in the requested order. The country sector is a showcase list. Verified real-time country rankings require authorized YouTube Analytics data. The site does not scan visitors' operating systems or fabricate analytics.
